# Event map image sources

Original Metin2 map imagery, downloaded unchanged from Gameforge’s Metin2 Wiki. Game imagery belongs to its respective owners (Webzen/Gameforge). Source pages and original image URLs are also recorded in lib/event-map-assets.json.

Pins use relative image positions, not inferred in-game coordinates. Castle Gate is an NPC appearing on several maps; choose the actual area to place a pin. Guild War Area has a separate image for each battle mode.
