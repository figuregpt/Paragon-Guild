# Visual guide screenshots

These PNGs capture the actual Paragon interface at a 390 px mobile viewport and 2x pixel density. They use only fictional local demo accounts (Aether, Kael, Nyx and Ragnar), sample PP, sample deposits and local events. They contain no production member information.

The notification settings capture previews server readiness through a local browser response fixture. It does not subscribe a device, send a notification or prove physical iPhone delivery. Native Safari menus and permission dialogs are not fabricated. The evidence image uses existing game artwork to illustrate the upload control, not to claim real attendance.

The guide at `/how-to-use` presents short instructions with these examples. Images can be opened at their original resolution. Refresh the captures when their corresponding UI changes, using an isolated local demo with production Discord and push jobs disabled.

Demon Tower and PvE form captures use the Experienced demo account with a 10 PP Demon Tower and 35 PP PvE selection. Neither capture submits an event. The step-by-step guide uses these alongside the Custom form to keep the shown type and reward accurate.
